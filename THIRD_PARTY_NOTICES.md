## Advertising dataset

The linear-regression module uses the Advertising dataset accompanying
*An Introduction to Statistical Learning* by Gareth James, Daniela Witten,
Trevor Hastie, and Robert Tibshirani.

- Source: https://www.statlearning.com/resources-second-edition
- Download: https://www.statlearning.com/s/Advertising.csv

The source page supplies a download but does not state an explicit
redistribution license for this CSV. The raw dataset is downloaded separately
into a Git-ignored directory. The repository contains experiment summaries,
model coefficients, and figures generated by its own plotting code. The saved
notebook does not include a table of raw dataset rows.

Attribution identifies the source; it does not replace any permission required
by the rights holder. This repository's MIT License does not grant rights to
the underlying dataset.

## Software dependencies

The code imports NumPy, pandas, Matplotlib, and scikit-learn. Jupyter/IPython
provides the notebook environment, and pytest provides the test runner.
Dependencies are declared in `pyproject.toml` and the tested environment is
recorded in `requirements-lock.txt`.

These packages are installed separately rather than copied into this
repository. Their respective upstream licenses continue to apply.
